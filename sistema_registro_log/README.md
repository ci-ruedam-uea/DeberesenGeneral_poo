# Cuenta Bancaria POO en Python

## Descripción del proyecto
Este proyecto fue desarrollado como parte de la **Tarea Semana 7: Implementación de Constructores y Destructores en Python**.  
El programa aplica los principios de **Programación Orientada a Objetos (POO)** utilizando una arquitectura separada en **modelos y servicios**.

El sistema simula una **cuenta bancaria**, permitiendo al usuario ingresar datos por teclado y realizar operaciones básicas mediante un menú interactivo.

---

## Objetivo
Aplicar correctamente el uso del **constructor (__init__)** y el **destructor (__del__)** en Python, demostrando su funcionamiento dentro de un programa estructurado con buenas prácticas de POO.
