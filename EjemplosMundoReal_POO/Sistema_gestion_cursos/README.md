# Sistema de Gestión de Cursos - Programación Orientada a Objetos

## Descripción del proyecto
Este proyecto desarrolla un sistema de gestión de cursos para un instituto o academia, utilizando Programación Orientada a Objetos (POO) y modularidad en Python.

El sistema separa las responsabilidades en distintos módulos, permitiendo una estructura clara, organizada y fácil de mantener.

## Estructura del proyecto
- `main.py`: archivo principal que inicia y controla la ejecución del sistema.
- `curso.py`: define la clase Curso.
- `estudiante.py`: define la clase Estudiante.
- `instituto.py`: gestiona la lista de cursos disponibles.
- `README.md`: documentación del proyecto.

## Funcionalidades
- Visualización de cursos disponibles.
- Matrícula de estudiantes en cursos.
- Control de cupos.
- Interacción mediante menú en consola.

## Conceptos aplicados
- Programación Orientada a Objetos.
- Modularidad.
- Encapsulación.
- Interacción entre clases.

## Estructura del proyecto
El proyecto está organizado en paquetes para aplicar modularidad:

- modelos: contiene las clases principales del sistema.
- servicios: contiene la lógica de gestión.
- main.py: punto de entrada del programa.
